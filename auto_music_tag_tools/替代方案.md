# 豆瓣音乐批量处理 - 替代方案

由于豆瓣音乐有较强的反自动化检测机制，完全自动化方案可能不稳定。以下是推荐的替代方案：

## 方案 A：半自动化（推荐）

### 工作流程

1. **运行脚本生成搜索链接列表**
```bash
python scripts/generate_search_links.py
```

2. **在浏览器中批量打开链接**
   - 脚本会生成一个 HTML 文件，包含所有专辑的豆瓣搜索链接
   - 点击按钮即可在新标签页打开搜索结果

3. **手动标记和添加标签**
   - 对于找到的专辑：点击"听过"，添加标签
   - 对于未找到的专辑：记录后手动创建

### 优点
- 稳定可靠，不会触发反爬虫
- 用户可以快速确认匹配是否正确
- 可以一次性处理多个专辑

### 缺点
- 需要手动操作，但速度仍然很快

---

## 方案 B：使用豆瓣 Cookie 的 API 调用（需要技术）

豆瓣的部分功能可以通过直接调用 API 完成：

### 标记已听
```
POST https://music.douban.com/j/subject/{subject_id}/interest
Content-Type: application/x-www-form-urlencoded
Cookie: dbcl2=xxx; ck=xxx

interest_type=listen  # 听过
```

### 添加标签
```
POST https://music.douban.com/j/tag/{subject_id}/add
Content-Type: application/x-www-form-urlencoded
Cookie: dbcl2=xxx; ck=xxx

tag=艺术家名
```

### 使用方法
```bash
python scripts/douban_api_simple.py
```

### 优点
- 不需要浏览器
- 速度快

### 缺点
- 需要知道专辑的 subject_id（仍需搜索获取）
- API 可能变化

## 方案 C：使用现有工具

有一些第三方工具可以用来管理豆瓣音乐：

1. **豆瓣助手**（浏览器扩展）
   - 可以快速标记和添加标签
   - 支持批量操作

2. **油猴脚本**
   - 搜索 "豆瓣音乐增强" 等脚本
   - 提供批量标记功能

## 当前脚本的使用（如果豆瓣检测不严格时）

```bash
# 测试模式
python scripts/run_douban_automation.py --test

# 如果遇到验证码或检测，停止并使用方案 A
```

## 生成的文件说明

| 文件 | 用途 |
|------|------|
| `scripts/douban_automation.py` | 完整自动化脚本 |
| `scripts/run_douban_automation.py` | 主启动脚本 |
| `scripts/generate_search_links.py` | 生成搜索链接（方案 A） |
| `scripts/douban_api_simple.py` | 简单 API 调用（方案 B） |
| `scripts/get_douban_cookie.html` | Cookie 获取工具 |
| `scripts/douban_cookie.txt` | Cookie 文件 |

---

## 建议的工作流程

1. **先测试自动化脚本**
   ```bash
   python scripts/run_douban_automation.py --test
   ```

2. **如果不工作（触发检测），使用方案 A**
   ```bash
   python scripts/generate_search_links.py
   # 打开生成的 search_links.html
   ```

3. **对于重要专辑，手动处理**
   - 访问 https://music.douban.com
   - 搜索专辑名
   - 标记"听过"并添加标签

---

## 标签建议

推荐为古典音乐专辑添加以下标签：
- **艺术家名**（如：Andrei Vieru）
- **作曲家名**（如：Bach, Debussy）
- **厂牌名**（如：ECM, Philips, DG）
- **音乐类型**（如：古典，钢琴）
