# 豆瓣音乐批量处理工具 - 使用指南

## 📚 目录结构

```
classical-music-db/
├── scripts/
│   ├── install.bat                    # 一键安装依赖 (首次使用)
│   ├── run.bat                        # 一键启动脚本
│   ├── run_douban_automation.py       # 主启动脚本
│   ├── douban_automation.py           # 核心自动化逻辑
│   ├── get_douban_cookie.html         # Cookie 获取工具
│   ├── douban_cookie.txt              # Cookie 文件 (需手动创建)
│   ├── QUICKSTART.md                  # 快速入门
│   └── README_DOUBAN.md               # 详细文档
├── A Portrait of Giacomo Lauri-Volpi Vol. 1/
├── A Portrait of Giacomo Lauri-Volpi Vol. 2/
└── ... (共 370 个专辑目录)
```

---

## 🚀 快速开始

### 方法一：使用批处理文件 (推荐 Windows 用户)

**首次使用**：
1. 双击运行 `scripts/install.bat`
2. 等待安装完成

**开始处理**：
1. 获取豆瓣 Cookie (见下方)
2. 双击运行 `scripts/run.bat`
3. 选择运行模式

### 方法二：命令行

```bash
# 测试模式 (推荐首次使用)
python scripts/run_douban_automation.py --test

# 处理所有专辑
python scripts/run_douban_automation.py --all

# 查看将要处理的专辑 (不执行)
python scripts/run_douban_automation.py --dry-run
```

---

## 🔑 获取豆瓣 Cookie

### 方法 A：使用图形化工具

1. 在浏览器中打开 `scripts/get_douban_cookie.html`
2. 确保已登录豆瓣账号
3. 点击"获取 Cookie"按钮
4. 点击"复制到剪贴板"
5. 创建文件 `scripts/douban_cookie.txt`
6. 粘贴并保存

### 方法 B：手动获取

1. 访问 https://music.douban.com 并登录
2. 按 `F12` 打开开发者工具
3. 切换到 **Application** (或 **存储**) 标签
4. 展开 **Cookies** → 选择 `https://music.douban.com`
5. 复制以下 Cookie 的值：
   - `dbcl2` (最重要)
   - `gr`
   - `ck`
   - `douban-fav-remind`
6. 格式：`dbcl2=xxx; gr=xxx; ck=xxx; douban-fav-remind=xxx`
7. 保存到 `scripts/douban_cookie.txt`

## ⚙️ 运行模式

| 模式 | 命令 | 说明 |
|------|------|------|
| 测试 | `--test` | 处理前 5 个专辑，验证环境 |
| 完整 | `--all` | 处理所有 370 个专辑 |
| 单字母 | `--letter A` | 只处理 A 开头的专辑 |
| 从指定字母开始 | `--from B` | 从 B 开头开始处理 |
| 空运行 | `--dry-run` | 只扫描目录，不执行操作 |
| 无头模式 | `--headless` | 不显示浏览器 (后台运行) |

### 组合使用示例

```bash
# 测试 A 开头的专辑
python scripts/run_douban_automation.py --letter A --test

# 从 M 开始处理，无头模式
python scripts/run_douban_automation.py --from M --headless --all

# 查看 B 开头的专辑有哪些
python scripts/run_douban_automation.py --letter B --dry-run
```

## 📊 输出文件

### JSON 结果文件

文件名：`douban_results_YYYYMMDD_HHMMSS.json`

```json
[
  {
    "directory": "A Portrait of Giacomo Lauri-Volpi Vol. 1 (Gala 4CD)",
    "title": "A Portrait of Giacomo Lauri-Volpi Volume 1",
    "artist": "Giacomo Lauri-Volpi",
    "status": "marked",
    "url": "https://music.douban.com/subject/xxxxx/",
    "message": "已标记，匹配度：0.85"
  }
]
```

**状态说明**：
- `marked` - 已找到并标记为"已听"
- `created` - 已创建新条目
- `not_found` - 未找到匹配 (需要手动创建)
- `unknown` - 处理状态未知

### Markdown 报告

文件名：`douban_results_YYYYMMDD_HHMMSS.md`

包含：
- 处理摘要统计
- 已标记专辑列表 (带链接)
- 未找到专辑列表 (需手动创建)

---

## 🏷️ 标签规则

脚本会自动为每个专辑添加以下标签：

1. **艺术家名** - 从专辑信息提取
   - 例：`Giacomo Lauri-Volpi`

2. **厂牌名** - 从唱片信息提取
   - 例：`Gala`, `ECM`, `Philips`, `DG`

3. **作曲家名** - 从曲目列表提取 (最多 3 个)
   - 例：`Puccini`, `Verdi`, `Bach`

## ⚠️ 注意事项

### 1. 豆瓣限制

- **无官方 API** - 使用浏览器自动化
- **可能触发验证码** - 遇到时暂停，手动完成
- **Cookie 有效期** - 约几天，过期需重新获取
- **创建条目限制** - 目前不支持用户直接创建

### 2. 处理速度

- 每个专辑约 **10 秒** (包含延迟)
- 370 个专辑约 **60 分钟**
- 建议分批处理，避免触发反爬虫

### 3. 建议流程

1. **测试环境** - 使用 `--test` 运行
2. **单字母测试** - 使用 `--letter A` 测试
3. **分批处理** - 按字母顺序分批
4. **定期检查** - 查看是否有验证码

## 🔧 故障排除

### Cookie 无效

```
错误：Cookie 无效或已过期，请重新获取
```

**解决**：重新获取 Cookie，保存到 `scripts/douban_cookie.txt`

### 触发验证码

**解决**：
1. 暂停脚本
2. 在浏览器中手动完成验证码
3. 等待 10-15 分钟
4. 继续运行

### 未找到专辑

对于标记为 `not_found` 的专辑：

1. 手动访问 https://music.douban.com
2. 搜索专辑名称
3. 如无结果，访问 https://music.douban.com/new_subject 提交

### Playwright 安装失败

```bash
# 手动安装
python -m pip install playwright
playwright install chromium
```
